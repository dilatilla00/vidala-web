# Vidala — Web

Minimal, geometrik bir vida bulmaca oyunu. Tarayıcıda oynanır, telefonda ana ekrana eklenebilir.

**Oyna:** https://dilatilla00.github.io/vidala-web/

Renkli vidaları üst üste binmiş plakalardan sök, aynı renkteki kutulara yerleştir. Plakalar tek vidada kalınca sallanır, son vidası çıkınca düşer ve birbirine çarpar. Bekleme alanı dolarsa oyun biter.

- Her zaman çözülebilir, giderek zorlaşan bölümler; her 5. bölüm "Zor Bölüm"
- Bölüm haritası, ilerleme tarayıcıda saklanır
- 2B fizik, kodla sentezlenen sesler
- Tek dosya (`index.html`), kütüphane yok
